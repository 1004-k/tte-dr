# Patterns submission naming conventions

Use these clean names for the journal upload package.

## Main manuscript

- `Manuscript_Patterns_TTEDR_resource_revised.docx`

## Graphical abstract

- `Graphical_Abstract_TTEDR.pdf`
- `Graphical_Abstract_TTEDR.png`

## Main figures

- `Figure_1_TTEDR_grade_heatmap.pdf`
- `Figure_2_reference_class_representatives.pdf`
- `Figure_3_TTEDR_diagnostic_snapshot.pdf`

## Main tables

- `Table_1_reference_class_representatives.csv`
- `Table_2_canonical_slice_summary.csv`

## Supplemental information

- `Document_S1_supplemental_information.docx`
- `Figure_S1_cutoff_sensitivity.pdf`
- `Table_S1_full_TTEDR_summary.csv`

## Notes

- Direction changes around the causal null are informational notes, not dominant grading flags.
- Delta* values shown as `>2.0` indicate no tipping within the evaluated range.
