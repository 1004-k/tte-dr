# Patterns submission checklist for TTE-DR

## Required before submission

- [ ] Create public GitHub release.
- [ ] Archive the release on Zenodo.
- [ ] Insert GitHub release URL, commit hash, and Zenodo DOI into:
  - manuscript key resources table
  - reference list
  - `CITATION.cff`
- [ ] Upload main figures as separate high-resolution PDF files.
- [ ] Upload the graphical abstract as PDF and/or PNG.
- [ ] Upload main tables as editable tables or CSV files.
- [ ] Upload `Document_S1_supplemental_information.docx`, `Figure_S1_cutoff_sensitivity.pdf`, and `Table_S1_full_TTEDR_summary.csv`.
- [ ] Confirm the declaration of interests form is complete.
- [ ] Confirm the cover letter explains background, conceptual advance, significance, and potential impact.

## Final artifact names

See `docs/NAMING_CONVENTIONS.md`.

## Editorial framing

Frame the paper as a reusable diagnostic reporting resource for auditable per-protocol target trial emulation, not as a new estimator. The strongest pitch is that TTE-DR converts fragmented robustness diagnostics into a reproducible, machine-readable QA report with a one-page snapshot for review and decision workflows.
