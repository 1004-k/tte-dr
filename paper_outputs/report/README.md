# TTE-DR report output

This directory contains a curated copy of the diagnostic snapshot used in the manuscript.

- `TTE_DR_diagnostic_snapshot.pdf`: one-page report snapshot corresponding to Figure 3.

The full Markdown report is generated by `scripts/35_make_patterns_report_md.R` during a fresh run. It is not stored here by default to avoid keeping stale run-specific logs or outdated diagnostic summaries in the public repository.
